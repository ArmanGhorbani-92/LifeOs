# LIFEOS — اپلیکیشن مدیریت زندگی و برنامه‌ریزی شخصی (Native Android)

اپلیکیشن کاملاً بومی اندروید (**Kotlin + Jetpack Compose + Material 3**) با رابط کاربری فارسی و راست‌چین (**RTL**)، فونت **Vazirmatn**، تم روشن و تاریک با طراحی **Glassmorphism** (سبز زیتونی `#71805A`، سرمه‌ای `#17263F` و سفید `#FFFFFF`) و ذخیره‌سازی کاملاً آفلاین و محلی با **Room Database** و **DataStore Preferences**.

## ویژگی‌های پیاده‌سازی‌شده

- **داشبورد**: تاریخ امروز شمسی، روز هفته، ساعت زنده، خوشامدگویی، آمار واقعی وظایف امروز و عقب‌افتاده، پیشرفت روزانه، ۶ کارت داده‌محور، نمودار عملکرد هفتگی، پیش‌نمایش برنامه زمانی و ۵ دکمه دسترسی سریع.
- **مدیریت وظایف**: ایجاد، ویرایش، حذف با تأییدیه، تکمیل، اولویت‌های چهارگانه، وضعیت‌های چهارگانه، جست‌وجو، مرتب‌سازی، فیلترهای زمانی/اولویت/دسته‌بندی و ۳ حالت نمایش (فهرست، کارت، گروه‌بندی بر اساس وضعیت).
- **برنامه‌ریزی دستی**: نمای روزانه، هفتگی و ماهانه همراه با خط زمانی ساعتی و هشدار تداخل زمانی بدون جابه‌جایی خودکار.
- **مدیریت اهداف**: پیشرفت دستی، مراحل هدف (Milestones)، تاریخچه پیشرفت، فیلتر وضعیت و بازه زمانی.
- **مدیریت عادت‌ها**: تناوب روزانه/چند روز در هفته/هفتگی/روزهای انتخابی، ثبت و لغو واقعی روزانه، محاسبه استمرار فعلی و بهترین استمرار، تقویم ۱۴ روزه و نمودارهای هفتگی و ماهانه.
- **تقویم کامل فارسی**: تبدیل دقیق شمسی و میلادی (با پشتیبانی کامل از سال‌های کبیسه)، نماهای ماهانه، هفتگی و روزانه و مدیریت رویدادها.
- **پروژه‌ها**: مدیریت پروژه‌ها، اتصال وظایف به پروژه و پیگیری پیشرفت.
- **یادداشت‌ها**: ویرایشگر فارسی RTL، سنجاق کردن، دسته‌بندی، برچسب‌ها، جست‌وجو و مرتب‌سازی.
- **تحلیل و گزارش‌ها**: آمار واقعی، فیلترهای زمانی (امروز، این هفته، این ماه، سه ماه اخیر و بازه دلخواه) و ۸ نمودار تعاملی فارسی.
- **تنظیمات، اعلان‌های محلی و پشتیبان‌گیری**: تغییر تم (روشن، تاریک، سیستم)، تقویم شمسی/میلادی، ساعت ۲۴/۱۲ ساعته، ارقام فارسی/انگلیسی، اعلان‌های محلی با درخواست مجوز در زمان نیاز، خروجی و بازیابی نسخه JSON با پیش‌نمایش و تأیید کاربر (SAF) و پاک‌سازی چندمرحله‌ای.

## اجرای پروژه و ساخت خروجی

1. پروژه را با Android Studio یا Gradle (JDK 11+ و Android SDK 36) باز کنید.
2. اجرای تست‌های واحد:
   ```bash
   gradle :app:testDebugUnitTest
   ```
3. ساخت فایل APK نسخه دیباگ:
   ```bash
   gradle :app:assembleDebug
   ```
4. ساخت Android App Bundle (AAB):
   ```bash
   gradle :app:bundleRelease
   ```
   *(توجه: اپلیکیشن هیچ‌گونه کلید API، اتصال اینترنت یا سرویس ابری نیاز ندارد و به‌صورت کاملاً مستقل روی دستگاه اجرا می‌شود.)*
